# Δημιουργία installer RestaurantOrders 17.3.132

Απαιτούνται Windows x64, .NET 8 SDK x64 και Inno Setup 6.
Άνοιξε PowerShell στον βασικό φάκελο του source.

Ο installer περιλαμβάνει και τις δύο εκδόσεις. Κατά την εγκατάσταση επιλέγεται:

- Μόνο Take Away
- Παραγγελιοληψία και Take Away

Για τη δημιουργία του installer:

```powershell
 .\installer\windows\Build-Installer.ps1 -Version 17.3.132
```

Τα αρχεία setup και τα SHA-256 δημιουργούνται στον φάκελο `artifacts\installer`.
Η επιλογή έκδοσης αποθηκεύεται στο τοπικό `appsettings.Installed.json` και δεν αλλάζει τη βάση.
Κατά την εγκατάσταση επιλέγεις φάκελο και όνομα αρχείου SQLite. Σε αναβάθμιση προτείνονται ξανά οι αποθηκευμένες επιλογές.
Σε αναβάθμιση, διάλεξε ξανά την έκδοση που θέλεις να παραμείνει εγκατεστημένη.
Η διεύθυνση του License Manager ρυθμίζεται εσωτερικά από το Setup και δεν εμφανίζεται σε σελίδα εγκατάστασης. Σε νέα εγκατάσταση και σε αναβάθμιση χρησιμοποιείται `https://texn-support.ddns.net`.
Κάθε εγκατάσταση δημιουργεί δικό της κλειδί ECDSA P-256. Το ιδιωτικό κλειδί αποθηκεύεται κρυπτογραφημένο από το Windows DPAPI στο `C:\ProgramData\RestaurantOrders\license-client-key.dpapi` και δεν φεύγει από τον υπολογιστή. Ο server κρατά μόνο το δημόσιο κλειδί στη βάση και ελέγχει με αυτό την υπογραφή κάθε αιτήματος. Η υπογραφή περιλαμβάνει χρόνο και τυχαίο nonce· παλιά αιτήματα δεν γίνονται δεκτά ξανά. Το προηγούμενο bearer token αφαιρείται μετά την πρώτη επιτυχημένη σύνδεση με το νέο πρωτόκολλο. Όταν ο server απαντήσει ότι η εγκατάσταση είναι σε αναμονή, το POS αφαιρεί τυχόν παλιά τοπική άδεια μέχρι να του ανατεθεί νέα.
Η σύνδεση με τον License Manager χρησιμοποιεί `https://texn-support.ddns.net`. Η υπογραφή προστατεύει την αυθεντικότητα των αιτημάτων, ενώ το HTTPS κρυπτογραφεί τη σύνδεση και πιστοποιεί τον server.
Μετά την εγκατάσταση, η σελίδα άδειας του POS εμφανίζει τον Κωδικό εγκατάστασης. Το POS τον καταχωρίζει στον License Manager όταν συνδεθεί πρώτη φορά στον server, είτε μέσω τοπικού δικτύου είτε μέσω Internet. Από εκεί γίνεται ενεργοποίηση, ανανέωση, ακύρωση ή αποσύνδεση συσκευής. Χωρίς Internet το POS συνεχίζει με την τελευταία έγκυρη υπογεγραμμένη άδεια έως 30 ημέρες.
Αν το Inno Setup βρίσκεται σε διαφορετικό φάκελο, όρισε τη μεταβλητή `INNO_SETUP_COMPILER` με την πλήρη διαδρομή του `ISCC.exe`.
